# Meridian — Revenue Intelligence

Интерактивная аналитическая платформа для выручки: один синтетический датасет и **десять принципиально разных визуальных концепций** одного и того же продукта. Не статичные макеты — рабочий интерфейс: периоды, сегменты, поиск, сортировка, карточки аккаунтов, палитра команд, экспорт CSV.

**Стек:** Vite 6 · React 19 · TypeScript. Сборка статическая, деплой — Cloudflare Pages.

## Возможности

- **Студия концепций** — сетка постеров всех десяти тем с мгновенным переключением.
- **Командная палитра** — `⌘K` / `Ctrl+K`: переход к концепции, периоду, сегменту, экспорт.
- **Горячие клавиши** `1`…`0` — переключение концепций.
- **Фильтры** — период (7 / 30 / 90 / 365 дней), сегмент (все / Enterprise / Mid / SMB), поиск по аккаунтам (фокус сохраняется при перерисовке).
- **Drawer аккаунта** — MRR, здоровье, места, динамика за 24 недели, LTV, риски.
- **Экспорт CSV** — текущая выборка аккаунтов.
- **Переходы** — View Transitions API с занавесом-подложкой; при `prefers-reduced-motion` мгновенно.
- **Адаптив** — от 390 px до широких экранов; графики имеют отдельные мобильные версии.

## Архитектура

Гибрид: React владеет каркасом, состоянием и загрузкой чанков; разметка каждой темы остаётся строковым шаблоном, чтобы сохранить попиксельную верность исходным макетам.

```
index.html                    каркас, boot-экран, инлайн-установка data-theme до первого кадра
src/main.tsx                  createRoot
src/App.tsx                   шелл: состояние → ViewModel → ленивая тема, hash-роутинг
src/lib/data.ts               детерминированный датасет + buildViewModel + форматтеры
src/lib/store.ts              состояние на useSyncExternalStore + localStorage
src/lib/shell.ts              императивный слой: студия, палитра, drawer, тосты,
                              делегация событий, переключение тем (View Transitions)
src/lib/charts.ts             геометрия графиков: линии, площади, дуги, hover-тултипы
src/lib/ui.ts                 переиспользуемые контролы и иконки
src/lib/overlays.ts           разметка студии, палитры и drawer
src/lib/themes.ts             реестр ленивых загрузчиков тем и постеров
src/themes/meta.ts            метаданные тем (eager, без постеров)
src/themes/<id>.tsx           render/mount/default-компонент одной концепции
src/themes/posters/<id>.ts     постер концепции (ленивый чанк, нужен только студии)
src/styles/base.css           общий слой: сброс, токены, оверлеи, тултипы
src/styles/studio.css         хром студии и постеры концепций
src/styles/themes/*.css       по одному файлу на концепцию
public/assets/fonts/          локальные woff2 (без внешних CDN)
public/_headers               правила кеша и безопасности для Cloudflare Pages
tools/                        служебные скрипты (шрифты, скриншоты)
```

Оптимизация:

- **Code-splitting по темам.** `React.lazy` + динамический `import()` дают отдельный JS и отдельный CSS на концепцию: первая загрузка тянет только активную тему. `React.memo` не даёт перерисовывать тему при перерисовке шелла.
- **Постеры отдельно.** Студия подгружает десять крошечных чанков с постерами при открытии; сама страница их не грузит.
- **Предзагрузка.** Наведение на карточку темы запускает `import()` её чанка — переход идёт без ожидания сети.
- **Вендоры в отдельном чанке** (`vendor`), который кешируется между релизами; остальные чанки хешированы и кешируются навсегда (`public/_headers`).
- **Шрифты локальные**, подмножества latin + cyrillic, без обращений к CDN.

Состояние (тема, период, сегмент, сортировка, сравнение) хранится в `localStorage` под ключом `meridian.ui.v1`, тема дублируется в hash: `#azure`, `#noel`, …, `#orbital`, `#studio`.

## Локальный запуск

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

Проверка и сборка:

```bash
npm run typecheck  # tsc --noEmit
npm run build      # typecheck + vite build → dist/
npm run preview    # локальный просмотр собранного dist/
```

Скриншот любой темы (нужен `google-chrome`):

```bash
tools/shot.sh http://127.0.0.1:4173/#noel /tmp/noel.png 1440 1000
```

## Деплой на Cloudflare Pages

Подключён GitHub-репозиторий, сборка на стороне Cloudflare:

- **Framework preset:** Vite
- **Build command:** `npm run build`
- **Build output directory:** `dist`
- **Node version:** 20 или новее (`engines.node`)

`public/_headers` копируется в `dist` и задаёт кеширование: хешированные `/assets/*` — `immutable` на год, `index.html` — всегда ревалидируется. Роутинг на hash, поэтому rewrite-правила не нужны.
