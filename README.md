# Meridian — Revenue Intelligence

Интерактивная аналитическая платформа для выручки: один синтетический датасет и **десять принципиально разных визуальных концепций** одного и того же продукта. Не статичные макеты — рабочий интерфейс: периоды, сегменты, поиск, сортировка, карточки аккаунтов, палитра команд, экспорт CSV.

**Демо:** статический сайт, без сборки и зависимостей. Достаточно открыть `index.html`.

## Возможности

- **Студия концепций** — сетка постеров всех десяти тем с мгновенным переключением.
- **Командная палитра** — `⌘K` / `Ctrl+K`: переход к концепции, периоду, сегменту, экспорт.
- **Горячие клавиши** `1`…`0` — переключение концепций.
- **Фильтры** — период (7 / 30 / 90 / 365 дней), сегмент (все / Enterprise / Mid / SMB), поиск по аккаунтам.
- **Drawer аккаунта** — MRR, здоровье, места, динамика за 24 недели, LTV, риски.
- **Экспорт CSV** — текущая выборка аккаунтов.
- **Адаптив** — от 430 px до широких экранов; графики имеют отдельные мобильные версии.

## Структура

```
index.html            точка входа, подключение тем
css/base.css          общий слой: сброс, токены, оверлеи, тултипы
css/studio.css        хром студии и постеры концепций
css/themes/*.css      по одному файлу на концепцию
js/data.js            детерминированный датасет + buildViewModel + форматтеры
js/charts.js          геометрия графиков (линии, площади, дуги, hover)
js/ui.js              переиспользуемые контролы и иконки
js/overlays.js        разметка студии, палитры и drawer
js/main.js            состояние, hash-роутинг, переходы, тосты
js/themes/*.js        render/mount каждой концепции
assets/fonts/         локальные woff2 (без внешних CDN)
tools/                служебные скрипты (шрифты, скриншоты)
```

Состояние (тема, период, сегмент, сортировка) хранится в `localStorage`, тема дублируется в hash: `#azure`, `#noel`, …, `#orbital`, `#studio`.

## Локальный запуск

```bash
python3 -m http.server 4173 --bind 127.0.0.1
# → http://127.0.0.1:4173/
```

Любой статический сервер подойдёт: сборка не требуется.
